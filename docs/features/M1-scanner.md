# M1 스캐너 (F1 읽기)

PRD F1 중 "찾기와 보여 주기"까지 다룬다. 실제 정리(휴지통 이동, 명령 실행)는 M2에서 한다. M1에는 파일을 지우거나 옮기는 코드가 없다.

## 사용자 이야기
나는 저사양 Mac을 쓰는 개발자로서, 스캔 버튼 한 번으로 Xcode 개발 찌꺼기가 항목별로 얼마나 쌓였는지, 무엇이 지워도 안전한지 보고 싶다. 그래야 정리할 대상을 고를 수 있다.

## 수용 기준
- [ ] 대상은 `BuiltinTargets`의 `CleanupTarget` 정의 목록으로 관리한다. 새 대상은 목록에 항목 하나만 추가하면 화면에 나타난다.
- [ ] 대상(PRD F1 표): DerivedData, iOS DeviceSupport, 기타 OS DeviceSupport(있을 때만), Archives, Xcode 캐시, SwiftPM 캐시(두 경로), 사용 불가 시뮬레이터 기기, CocoaPods 캐시(있을 때만), Homebrew 캐시(brew가 있을 때만), 로컬 스냅샷(정보만, 개수 표시). 시뮬레이터 런타임은 M3(F2)의 시뮬레이터 화면에서 다룬다.
- [ ] "스캔"을 누르면 모든 대상을 병렬로(`.utility` 우선순위) 스캔하고, 끝난 대상부터 화면에 용량이 나타난다. 나머지는 진행 표시를 유지한다.
- [ ] 용량은 `totalFileAllocatedSize` 합계이고 하드링크는 한 번만 센다. `du -sk` 결과와 5% 이내로 일치한다.
- [ ] 읽기 권한이 없는 대상은 "권한 없음"을 표시하고 다른 대상의 스캔은 계속된다. 외부 명령이 실패하면 그 대상만 "확인 불가"를 표시한다.
- [ ] 스캔 중 "취소"를 누르면 즉시 멈추고, 끝나지 않은 대상은 "취소됨"으로 표시한다.
- [ ] 스캔이 끝나면 "안전" 대상의 항목은 기본 선택, "주의" 대상은 기본 미선택이다. "정보만" 대상은 선택할 수 없다.
- [ ] 그룹 행: 체크박스(일부 선택 시 혼합 상태), 이름, (i) 설명 팝오버, 안전도 배지, 합계 용량. 하위 행: 이름, 마지막 수정일, 용량, 우클릭 "Finder에서 보기". 명령으로 정리하는 대상(사용 불가 시뮬레이터)은 그룹 단위로만 선택한다.
- [ ] DerivedData 항목 이름은 해시 꼬리를 뗀 프로젝트 이름으로 보여 준다(예: `NativeStarter-ayoa…` → `NativeStarter`).
- [ ] 하단 바에 "선택 N.NGB"와 "스캔"/"다시 스캔" 버튼이 있다.
- [ ] UI 테스트 모드에서는 실제 디스크를 읽지 않고 고정된 가짜 대상(같은 id·제목·안전도)을 쓴다.

## 위험 요소
- 대용량 폴더 스캔이 메모리를 많이 쓰는 문제: 하드링크 식별자는 링크 수가 2 이상인 파일만 기억한다.
- 외부 명령(`xcrun simctl list`, `tmutil listlocalsnapshots`, `brew --cache`)은 읽기 전용이고 `ShellRunner` 타임아웃(30초)을 따른다.
- 이 단계에는 삭제 코드가 없다.
