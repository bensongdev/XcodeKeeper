# M0 뼈대

PRD 마일스톤 M0. 이후 기능(F1~F4)을 얹을 앱 구조와 공용 서비스를 만든다.

## 사용자 이야기
나는 저사양 Mac을 쓰는 개발자로서, Dock 아이콘 없이 메뉴바에 있는 앱에서 여유 공간을 보고 스캐너 창과 설정 창을 열고 싶다. 그래야 이후 단계의 정리·모니터 기능을 한곳에서 쓸 수 있다.

## 수용 기준
- [ ] 앱은 Dock 아이콘 없이 실행된다 (`LSUIElement = YES`).
- [ ] 메뉴바에 `internaldrive` 아이콘과 여유 공간 숫자(예: `16G`, 10^9 바이트 기준, 내림)가 표시된다. 여유 공간을 읽지 못하면 `—`를 표시한다.
- [ ] 메뉴바 팝오버(폭 320pt)에 "여유 16.2GB" 형식의 한 줄, "스캐너 열기", "설정…", "종료" 버튼이 있다.
- [ ] 스캐너 창(최소 720×520pt)의 사이드바에 "개발 찌꺼기", "시뮬레이터", "정리 이력" 세 항목이 있고, 처음에는 "개발 찌꺼기"가 선택되어 있다. 항목을 고르면 오른쪽 제목이 그 항목 이름으로 바뀐다.
- [ ] 설정 창이 열리고 "메뉴바에 여유 공간 숫자 표시" 토글이 있다(기본 켬). 끄면 메뉴바에 아이콘만 남는다.
- [ ] `ShellRunner`는 실행 파일과 인자를 받아 종료 코드, stdout, stderr를 돌려준다. 기본 타임아웃은 30초이고, 시간을 넘기면 프로세스를 종료하고 `timedOut` 오류를 낸다. 호출한 Task가 취소되면 프로세스를 종료하고 `CancellationError`를 낸다. 실행 파일이 없으면 `launchFailed` 오류를 낸다.
- [ ] App Sandbox는 꺼져 있다 (`~/Library/Developer` 접근, `xcrun` 실행을 위해).
- [ ] UI 테스트 모드(`-UITestMode YES`)에서는 실제 디스크 대신 고정된 여유 공간(16.2GB)을 쓴다.

## 위험 요소
- 샌드박스 해제: 앱이 사용자 홈 전체에 접근할 수 있다. 삭제 코드는 M2의 `Cleaner` 한 곳에만 두고 허용 루트 검증을 거친다. M0에는 삭제 코드가 없다.
- `Process` 실행: M0에서는 `ShellRunner`가 테스트에서만 쓰인다. 외부 입력을 셸 문자열로 넘기지 않고 실행 파일 + 인자 배열로만 실행한다.
- Swift 6 strict concurrency 전환: `Process`가 Sendable이 아니므로 잠금으로 감싼 상자에 넣는다.
