# M2 정리 (F1 쓰기)

PRD 마일스톤 M2. 스캐너에서 선택한 항목을 휴지통 또는 공식 CLI로 정리하고 이력을 남긴다.

## 사용자 이야기
나는 저사양 Mac을 쓰는 개발자로서, 스캔에서 고른 항목을 확인 후 한 번에 정리하고 얼마나 확보했는지 보고 싶다. 그래야 macOS 업데이트에 필요한 공간을 빠르고 안전하게 만들 수 있다.

## 수용 기준
- [ ] 하단 바에 "휴지통으로 정리" 버튼이 있다. 선택한 항목이 없거나 스캔·정리 중이면 비활성이다.
- [ ] 누르면 확인 창이 열리고 선택 항목 수("항목 7개")와 예상 확보 용량("예상 확보 용량 6.9GB")을 보여 준다. 취소하면 아무것도 바뀌지 않는다.
- [ ] 명령으로 정리하는 대상(사용 불가 시뮬레이터 기기)이 선택되어 있으면, 확인 창에 "휴지통을 거치지 않고 `xcrun simctl delete unavailable`로 삭제된다"는 안내를 보여 준다.
- [ ] DerivedData가 선택되어 있고 Xcode(`com.apple.dt.Xcode`)가 실행 중이면 확인 창에 경고를 보여 주고, 확인 버튼 문구가 "그래도 정리"로 바뀐다.
- [ ] 파일 정리는 `Cleaner` 한 곳에서만 하고 `FileManager.trashItem`으로만 한다. 앱 코드에 `removeItem` 등 영구 삭제 호출이 없다.
- [ ] 휴지통으로 옮기기 직전 `PathGuard`가 경로를 검증한다: 파일 URL이고, `..`가 없고, 심볼릭 링크를 푼 실제 경로가 그 대상의 허용 루트와 같거나 그 안에 있어야 한다. 아니면 옮기지 않고 "허용되지 않은 경로"로 실패 처리한다.
- [ ] 항목 하나가 실패해도 나머지는 계속 정리하고, 실패한 항목과 이유를 결과에 보여 준다.
- [ ] 정리 중에는 진행 표시와 "취소" 버튼이 있고, 취소하면 남은 항목은 건드리지 않는다.
- [ ] 정리 후 "확보됨 N.NGB", "휴지통을 비워야 실제로 공간이 확보됩니다." 안내, "휴지통 열기" 버튼을 보여 주고 자동으로 다시 스캔한다.
- [ ] 정리 이력(일시, 항목, 용량)을 `~/Library/Application Support/XcodeKeeper/history.json`에 최신순 최대 100건 저장한다. 파일이 손상되어 읽지 못하면 덮어쓰기 전에 `history-corrupt-<시각>.json`으로 옮겨 둔다.
- [ ] "정리 이력" 화면에 기록별 일시·항목 수·확보 용량과 누적 합계를 보여 준다. 기록이 없으면 빈 상태 안내를 보여 준다.
- [ ] UI 테스트 모드에서는 실제 휴지통·명령·이력 파일을 쓰지 않는 가짜 정리기와 메모리 이력을 쓴다.

## PRD와 다른 점 (승인 필요)
- PRD는 "휴지통 비우기 버튼"이지만, 앱이 휴지통을 비우려면 Finder 자동화 권한(AppleScript, 새 권한)이 필요하고 사용자의 다른 파일까지 영구 삭제된다. 이번 단계에서는 **"휴지통 열기"**(Finder에서 휴지통 창을 열고 사용자가 직접 비움)로 구현한다. 직접 비우기가 필요하면 권한 추가를 따로 승인받는다.
- Homebrew 캐시는 기본 위치(`~/Library/Caches/Homebrew`)만 허용 루트로 둔다. `HOMEBREW_CACHE`로 다른 곳을 쓰면 정리하지 않고 "허용되지 않은 경로"로 표시한다.

## 위험 요소
- 사용자 데이터 손실: 허용 루트 재검증, 휴지통만 사용, 삭제 코드 한 곳. 테스트는 임시 폴더와 가짜 휴지통만 쓴다. 개발 중 실제 Mac에서 정리를 실행하기 전에는 사용자에게 묻는다.
- `simctl delete unavailable`은 휴지통을 거치지 않는 영구 삭제다(PRD가 정한 공식 CLI). 확인 창에 명시한다.
- 영구 데이터: 이력 JSON 파일을 새로 만든다(PRD 비기능 요구사항).

## 테스트 계획
| 동작 | 테스트 방법 | 증거 |
|---|---|---|
| 허용 루트 검증(`..`, 루트 밖 심볼릭 링크, 비슷한 이름의 형제 폴더, 존재하지 않는 경로) | 단위 (`PathGuardTests`) | 테스트 로그 |
| 휴지통 이동, 명령 실행, 실패 격리, 취소 | 단위 (`CleanerTests`, 가짜 휴지통·셸) | 테스트 로그 |
| 스캔→정리→재스캔 | 통합 (임시 홈 + 가짜 휴지통) | 테스트 로그 |
| 이력 100건 상한, 저장/불러오기, 손상 파일 보존 | 단위 (`HistoryStoreTests`) | 테스트 로그 |
| 확인 창 / Xcode 실행 경고 / 정리 후 / 일부 실패 / 이력 화면 | UI assertion | `01-confirm-dialog`, `02-after-cleanup`, `03-history`, `01-xcode-running-warning`, `01-cleanup-partial-failure`, `01-history-empty` |
